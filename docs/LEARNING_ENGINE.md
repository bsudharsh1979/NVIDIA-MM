# Learning engine

Active lesson steps: EXPLAIN → VISUALIZE → PREDICT → EXPERIMENT → OBSERVE → EXPLAIN BACK → DIAGNOSE → PRACTICE → MASTERY UPDATE.

Socratic incorrect answers use the **Why am I wrong?** panel (belief, missing distinction, source, retry).

Teach-back is graded against required concept keywords and counts heavily in mastery.

Diagnostic covers fusion, XYZA, CLIP, projection, OCR, VSS, Graph-RAG, CILP.
