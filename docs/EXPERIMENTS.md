# Experiments

`POST /api/experiments/import` accepts JSON, CSV, AIPerf-shaped JSON, Prometheus, kubectl text, logs, OTEL JSON.

Comparison flags confounders (GPU count, concurrency, cold vs warm). Normalized tokens/sec/GPU when metadata includes `gpu_count`.

Explainer sections: what happened, important changes, likely explanations, alternatives, what to check, course connection. Correlation ≠ causation.
