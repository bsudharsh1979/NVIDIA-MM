# NVIDIA runtime (optional)

The web academy does **not** require NIM, Omniverse, or NVCF.

Suggested later attachments:

- NVIDIA NIM tutor (`NIM_BASE_URL`, `NVIDIA_API_KEY`) selected in Settings — never silent fallback
- VSS classroom (`via-server:8000`) is course material, not this app's inference backend
- Omniverse Kit app dropped into `integrations/omniverse-twin` + `deploy/docker` profile `omniverse`
- NVCF streaming documented in `docs/nvidia-omniverse-deployment.md`

Do not mix this multimodal course with Dynamo/Grove/KEDA facts unless you load a different course pack.
